\# Система учёта заявок



Учебный проект по дисциплине «Технологии разработки программного обеспечения».



\## Назначение

Система предназначена для регистрации, классификации, назначения исполнителей и контроля выполнения внутренних заявок организации.



\## Основные функции

\- создание заявки заявителем;

\- назначение исполнителя;

\- ведение статусов: Новая, В работе, Выполнена, Закрыта;

\- комментарии к заявке;

\- отчёты по нагрузке;

\- управление категориями и пользователями.



\## Структура

\- `docs/` — документация (ТЗ, AI-журнал, диаграммы)

\- `src/` — исходный код

\- `tests/` — тесты



\## Стек

Python 3.12+, SQLite, Git.

## Статус проекта
В разработке (лабораторные работы 1–5).
