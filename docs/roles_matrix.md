# Матрица прав ролей (итоговая, сверено с request_service.py и тестами)

| Действие | admin | operator | executor | applicant |
|---|---|---|---|---|
| Создать заявку | да | да | нет | да |
| Назначить исполнителя | да | да | нет | нет |
| Сменить статус | да | да | только своих | нет |
| Комментировать | да | да | да | да |
| Редактировать заявку | да | да | нет | нет |
| Удалить заявку | да | нет | нет | нет |
| Управлять справочниками | да | нет | нет | нет |

## Переходы статусов (1=Новая, 2=В работе, 3=Выполнена, 4=Закрыта)

| Из | В | Кто может |
|---|---|---|
| 1 Новая | 2 В работе | admin, operator, executor (только своей) |
| 2 В работе | 3 Выполнена | admin, operator, executor (только своей) |
| 3 Выполнена | 4 Закрыта | admin, operator |
| 4 Закрыта | — | терминальный, переходов нет |

## Отклонённые предложения ИИ

- ИИ разрешил applicant менять статус и закрывать заявку — **отклонено**, по решению варианта 1 заявитель только создаёт и комментирует.
- ИИ разрешил executor создавать заявку — **отклонено**, исполнитель не создаёт заявки.
- ИИ добавил переход `Выполнена → В работе` (возврат) и переоткрытие из «Закрыта» — **отклонено** для ЛР6 как усложнение; можно добавить позже.
- Редактирование/удаление заявки и управление справочниками — **не реализованы** в ЛР6 (отмечено на будущее).
