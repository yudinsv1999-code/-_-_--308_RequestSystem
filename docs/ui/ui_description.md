# Описание экранов интерфейса

1. **Экран входа:** Поля для ввода email и пароля. Сообщения об ошибках (например, «Неверный пароль»). После входа — редирект на список заявок.
2. **Главный экран (Список заявок):** Таблица с пагинацией. Поиск по номеру/теме. Фильтры по статусу и категории. Цветные бейджи статусов (Новая — синий, В работе — желтый, Выполнена — зеленый, Закрыта — серый). Кнопка «Создать заявку». Если список пуст, отображается заглушка «Заявок пока нет».
3. **Экран создания заявки:** Форма с валидацией. Обязательные поля: Тема, Описание, Категория. При успехе — уведомление «Заявка создана».
4. **Карточка заявки:** Полная информация (Заявитель, Исполнитель, Дата). Блок комментариев. Кнопка смены статуса (доступна в зависимости от роли).
5. **Экран редактирования:** Выпадающий список для смены статуса и выбора исполнителя. Кнопка «Сохранить». Кнопка «Удалить» (с модальным окном подтверждения).
